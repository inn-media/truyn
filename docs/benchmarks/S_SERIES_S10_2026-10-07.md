# TRUYN S-10 Semantic Integration Benchmark — 2026-10-07

Status: **ACCEPTED / PASS**

This report publishes the sanitized public result of the bounded S-10 ECON/MIX integration benchmark. It does not publish private managed-cloud topology, credentials, account identifiers, private endpoints, owner-only operational state or raw private request traces.

## Scope

S-10 is the small-scale live semantic integration baseline that precedes the larger S-50/S-100/S-200/S-500 ladder. It validates that the public TRUYN semantic/retrieval/provider contract remains correct and economically useful under a heterogeneous real-provider workload before larger semantic-node scale gates are attempted.

This result does **not** accept the full S-50 scenario matrix and does not imply S-100, S-200 or S-500.

## Workload

The accepted run exercised:

- 150 measured observations;
- three 50-worker assignment profiles:
  - balanced;
  - 60%-GPT skewed;
  - seeded-random;
- seven required text-provider families:
  - GPT;
  - Gemini;
  - Grok;
  - DeepSeek;
  - Llama;
  - Mistral;
  - Kimi.

Every profile contained all seven provider families.

## Token and cost measurements

Across the 150 measured observations:

- DIRECT input tokens: **1,661,796**
- TRUYN input tokens: **46,650**
- DIRECT output tokens: **4,708**
- TRUYN output tokens: **7,226**
- mean input-token reduction: **97.17417299653404%**

For the comparable GPT + Gemini priced subset captured by the benchmark continuity snapshot:

- DIRECT comparable provider cost: **$0.06252742**
- TRUYN comparable provider cost: **$0.00196582**
- comparable provider-cost reduction: **96.85606730615144%**

These are benchmark measurements for the frozen workload and pricing snapshot used by the run. They are not a claim about current universal provider pricing.

## Interpretation

The accepted S-10 result supports three bounded conclusions:

1. TRUYN semantic retrieval preserved measured correctness, provenance and minimal-context behavior across seven provider families in this workload.
2. The same workload used approximately 97.17% fewer provider input tokens through TRUYN than through the paired DIRECT path.
3. In this run, the reduced-context TRUYN path also improved aggregate p50 and p95 end-to-end latency.

No larger semantic-scale claim may be inferred from this result. S-50 and every larger S level require their own immutable acceptance evidence.
