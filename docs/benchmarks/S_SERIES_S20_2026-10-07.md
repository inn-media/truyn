# TRUYN S-20 Five-Scenario Semantic Benchmark — 2026-10-07

Status: **ACCEPTED / PASS**

This report publishes the sanitized public result of the accepted S-20 Attempt 3 benchmark. It does not publish private managed-cloud topology, credentials, account identifiers, private endpoints, owner-only operational state or raw request traces.

## Scope

S-20 is an intermediate live semantic-node gate inserted between the accepted S-10 integration baseline and the larger S-50 gate.

Attempt 3 accepts exactly these scenarios:

- `ECON`
- `MIX`
- `COST-ROUTING`
- `CONTENTION`
- `LANG`

It does **not** accept `XBORDER`, `CHAIN` or `CHURN`, and it does not substitute for S-50, S-100, S-200 or S-500.
