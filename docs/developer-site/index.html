Connect intelligence to intelligence.

First-party SDK/runtime surface for identity, authorized discovery, NEED/RESULT, signed partial results, direct NEED cancellation and reference-only artifacts. TRUYN/1 remains draft.

Start with TypeScript

import {
  TruynLocalNodeClient,
  createArtifactPayload
} from '@truyn/sdk';

const client = await TruynLocalNodeClient.connect({
  relayUrl: 'https://relay.example'
});

const receipt = await client.need(
  'reasoning.general',
  { question: 'Hello from TRUYN' }
);

const result = await client.waitForResult(receipt.needId);

DX-3 runtime surface

Streaming

Abortable relay event streams plus signed ordered PARTIAL deltas with correlation, idempotency and bounded backpressure. Deltas may carry tokens, but TRUYN does not prescribe tokenization.

Cancellation

Requester-owned direct NEED cancellation is enforced end to end. Provider work receives an AbortSignal; built-in persistent video jobs are cancelled remotely with bounded retry. Custom adapters remain cooperative.

Artifacts

Reference-only media/object payloads with MIME, byte count and SHA-256 integrity metadata.

Stable API

A separately versioned SDK contract. It does not imply that TRUYN/1 or all package releases are already stable.

Lifecycle boundary

Fast NEED and signed REVOKE share the same bounded fast lifecycle channel. Async requesters can inspect owner-only compact request status. Late RESULT/PARTIAL output after cancellation, completion or expiry fails closed. Chain-stage cancellation is not supported.

Security boundary

SDK calls use the same TRUYN authorization path as every other interface: authenticate → authorize → billing/entitlement → dispatch → provider recheck. Transport authentication is never TRUYN authorization, and cancellation metadata cannot assign provider ownership or billing responsibility.

Languages

JavaScript/TypeScript and Python have bounded reference clients. Go, Java and C#/.NET have the portable object/artifact payload parity slice and compiler gates; broader client parity/publication remains open. Rust remains an additional track.
