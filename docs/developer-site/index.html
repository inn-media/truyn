SDK stable API contract v1

Connect intelligence to intelligence.

First-party SDK surface for identity, authorized discovery, NEED/RESULT, event streams and reference-only artifacts. TRUYN/1 remains draft.

Start with TypeScript

import {
  TruynLocalNodeClient,
  createArtifactPayload
} from '@truyn/sdk';

const client = await TruynLocalNodeClient.connect({
  relayUrl: 'https://relay.example'
});

const receipt = await client.need(
  'reasoning.general',
  { question: 'Hello from TRUYN' }
);

const result = await client.waitForResult(receipt.needId);

DX-3 runtime surface

Streaming

Abortable async relay event streams. Token-delta streaming is not claimed until the wire contract exists.

Cancellation

Deterministic SDK-operation cancellation with normalized cancelled behavior.

Artifacts

Reference-only media/object payloads with MIME, byte count and SHA-256 integrity metadata.

Stable API

A separately versioned SDK contract. It does not imply that TRUYN/1 is already stable.

Security boundary

SDK calls use the same TRUYN authorization path as every other interface: authenticate → authorize → billing/entitlement → dispatch → provider recheck. A public SDK never grants access to another party's private or owner-funded provider.

Languages

JavaScript/TypeScript · Python · Go · Java · C#/.NET. Rust remains an additional track.
